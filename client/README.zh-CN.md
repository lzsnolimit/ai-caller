# 网页控制台 Client

Client 是独立的 HTML/JS 管理 UI。AI 与模型凭据在 `server/common/ai/`，不在浏览器中。

可以由 Server 的 `/` 同源提供，也可以单独运行静态服务。Client 只使用 HTTP/WS API，不直接控制蓝牙、ADB 或模型。

## 运行

```sh
python3 client/run.py
```

从仓库根目录运行，访问 `http://127.0.0.1:5173/`，在页面中填写 Server 地址。默认连接本机 8765；Server 使用其他端口时须更改地址。Server 断开后点“连接”重新读取快照。

从其他来源提供 Client 时，须把该来源加入 Server 的 `PHONE_CLIENT_ORIGINS`；默认允许端口 5173 上的 `localhost` 和 `127.0.0.1`。局域网主机名无法解析时，核对局域网 IP 地址。

## 界面

单页，三个分页：手机、通话、通话指令。页面顶部始终是线路指示灯：空闲（绿）、通话中（琥珀，呼吸动画）、恢复中（红）；旁边显示当前通话的手机、去电/来电、阶段、实时计时、恢复原因，以及“查看这通电话 / 挂断”。`prefers-reduced-motion` 时不播放动画。

- **语言：** 页面提供中文/英文切换。界面文案在 `assets/messages.js`。
- **主题：** 浅色纸张底和深色夜间配色，跟随系统 `prefers-color-scheme`；`?theme=dark|light` 可强制预览。
- **离线：** 只用系统字体和内联资源，离线可用。

地址栏支持 `#devices`、`#calls`、`#prompt`、`#calls/<conversationId>`、`#devices/pair`、`#devices/inbound/<address>`，可直接打开对应内容。

控制台为每个 Server 错误码显示易懂的提示（见 `assets/labels.js`）；未知错误码显示“操作失败（code）”。

## 功能与边界

- **手机：** 每部手机一行。标题优先显示蓝牙名称 `name`（Mac 上首次连接后才有）；没有名称或旧服务没有该字段时显示地址。地址只以等宽小字出现一次。一句话状态：可拨号和接听来电 / 已连接，电话功能还没就绪 / 已配对，未连接 / 电话状态待核对 / 通话中。主按钮：未连接 → “连接”，已连接 → “拨号”，正在通话 → “查看通话”；“断开 / 来电接待语 / 删除配对”在行内“⋯”菜单。标签显示自定义或默认接待语（旧服务没有 `inboundPrompt` 时不显示）和非默认音色。
- **添加手机：** 扫描、填地址、开始配对；数字比较确认、passkey/PIN 输入和取消都可用。
- **来电接待语：** `GET/PUT /v1/devices/{address}/inbound-prompt`，UTF-8 最多 16 KiB，本地先检查；系统保护规则折叠只读显示。保存只影响之后的来电。
- **通话记录：** “当前”置顶，其余记录从新到旧。每条显示 ↗ 去电 / ↙ 来电、手机名、开始时间（今天只显示时分）、时长（接通到结束；进行中实时计时）、结局（例如已挂断、对方挂断、手机没确认接听、没拨出去、收尾待确认，见 `labels.js`）。旧服务没有 `direction` 时按去电显示；没有 `line` 时按会话列表推断，不禁用拨号。
- **通话详情：** 标题、时间线、结局；进行中显示实时对话（气泡）、给 AI 的指令、监听（对方/AI 音量）、任务、已存盘的对话（按钮读取）；已结束时自动读取存盘的完整对话（`GET /v1/conversations/{id}/transcript`），相邻同一说话人的片段合并成一个气泡。从存盘加载、没有内存详情的会话只显示记录和对话。
- **拨号：** 手机、AI 音色（试听/停止）、号码、目的、预期结果、任务说明、从文件读入（UTF-8 `.txt/.md`，最多 64 KB）。线路非空闲时禁用并说明原因；所选手机待核对时提示但不禁用。
- **通话指令（共用 System Prompt）：** 保存到 Server，对下一次拨号生效，不修改旧任务。
- 切换对话时停止旧监听并清缓存，指令草稿按会话保留；关闭页面不会结束 Server 上的通话。

## 监听与指令

监听使用 Web Audio 播放 24 kHz PCM 副本，不采集麦克风，不回送到主通话。Server 的监听队列独立，慢速浏览器可能丢副本或被断开监听。

“发送”不等于 AI 已执行。指令状态区分：服务接收、模型连接写出、模型确认注入、拒绝及结果未知，并显示命令 ID 和更新时间。注入回执不证明模型已说出目标内容或对方已听到。本地保留单次非空指令最多 4096 字符的限制，不截断。模型另有 500 tokens 限制；模型返回关联拒绝时只标记该指令被拒绝，不结束通话。未知结果不会自动重发。详情标题可能残留旧的 `starting`；以实时列表和顶部线路状态判断实际状态。

首次开启监听可能有噪音，原因未查明。双方监听、指令效果和真机上当前通话与历史记录的切换未完整测试。

没有鉴权，API 只用于可信网络。不要把模型数据、电话号码和 task 内容写到普通日志。主通话有界队列不保证零延迟；浏览器监听的短缓冲不能算作手机到模型的延迟。

AI CLI 和测试在 [server/common/ai](../server/common/ai/README.zh-CN.md)。Client 没有 npm 依赖。

## 音色

拨号表单提供 13 个带项目样本的 AI 音色，可选择并点击试听，默认 `marin`。音色只影响下一次拨号，详情显示任务快照中的音色。项目已保存的试听直接播放，不调用云服务；缺少样本时才需 Server 单独生成短音频，可能产生 Live 费用和等待。“停止试听”停止本页的播放和等待。目录中的语言/地区描述声音风格，不限制对话语言。试听样本为固定英文短句，可能被截断，不能代表所有语言的读音。试听不会拨号，也不会更改已有通话。

选择音色会立即保存为所选已配对设备的默认值，不需要拨号或连接 HFP。Server 只在当前进程内记忆；刷新页面、切换设备或另一个 Client 读取时显示同一选择，服务重启后回到 `marin`。删除设备会清除其选择。已有通话和任务快照保持不变。保存失败会显示错误；读取完成前，页面不会把自己的默认值写回 Server。

## 实时转写

选择对话后，页面自动连接该会话的 `/v1/conversations/{id}/transcript/events`。这不会开始声音监听。对方和 AI 的文字分别显示，保留原始空格与重复文字。5 秒分组和近似会话时间仅用于显示，不表示说话回合结束或声音已播放。

转写通过独立的私有文件描述符从 AI worker 进入 Server，不进入普通日志。实时文字来自有界内存缓存：Server 最多缓存 64 个会话；每个会话最多 512 个增量或 128 Ki 字符，缓存淘汰时页面提示文字缺口。重新连接使用 `cacheId` 和 `after` 序号继续。完整对话另由 Server 存盘，不受缓存上限影响，服务重启后仍可用“打开完整转写”读取；号码不记录。文字与音频使用不同队列，慢速文字消费者会被断开，不会阻塞双向音频。
